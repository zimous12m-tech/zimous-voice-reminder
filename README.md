# Zimous Voice Reminder v2.1 (Web Universal)

Sistema inteligente de lembretes por voz e gestão de tarefas que corre diretamente no navegador do telemóvel (Android e iOS), sem necessidade de instalações complexas.

## Como usar
Basta aceder ao link público fornecido, criar o seu lembrete, gravar a sua nota de voz através do microfone do telemóvel e guardar. Os dados e áudios ficam armazenados de forma segura e privada no armazenamento local do seu próprio dispositivo.
